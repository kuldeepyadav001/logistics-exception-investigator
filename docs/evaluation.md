## MEASURED RESULT (2026-09-17, local pipeline, deterministic engine)

- `pytest tests/ -q` → **36/36 passing**, including:
  - `tests/evaluation/test_ground_truth.py` → **11/11 cases detect exactly the ground-truth exception types** (exact-set match per case).
  - Exception detection precision on the suite: **11/11 detected types correct, 0 false positives, 0 missed types** (denominator = 11 expected types across 11 cases).
  - Canonical case: variance +25 kg (3.067%) vs delivered; exposure $312.50; severity HIGH — all asserted in tests.
- Not yet measured (planned, Phase 6): extraction field-level accuracy on

## Harness usage

```bash
.venv/bin/python -m pytest tests/evaluation -v
```

Add a case: append a `CaseSpec` in `scripts/generate_dataset.py`, regenerate,
extend nothing else — the harness picks it up automatically.

## Baseline experiment (planned, Day 3–4)

Give a human (team member) 3 cases (C02, C07, C10) as raw PDFs; measure time
to (a) identify the exception, (b) state the correct affected fields,
(c) propose a resolution. Compare with system output + human review time on
the same cases. Record as MEASURED RESULT before any claim is made.
